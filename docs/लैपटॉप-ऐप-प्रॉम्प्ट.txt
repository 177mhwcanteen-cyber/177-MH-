चरण 1 ✅ (21-11) — सीधी छपाई (se-desk.js = window.SDK)
  - Web Serial (Chrome/Edge, Windows 10/11): ब्लूटूथ से pair प्रिंटर = "Standard Serial over Bluetooth link (COMx)"; USB-Serial वाले भी।
  - 🖨️ प्रिंटर (☰ → प्रिंटर जोड़ें / लेबल टैब ऊपर) में "💻 लैपटॉप / कंप्यूटर से सीधी छपाई": बिल 58/80mm/4 इंच, लेबल TSPL/रसीद; 🧪 जाँच; ✕।
  - SE.canDirect(role) / SE.rawPrint(addr,data,role) — फोन = BtPrinter (APK), लैपटॉप = SDK.send; बिल (printReceipt), लेबल (एक/सूची), रैक स्टिकर तीनों।
  - न जुड़े → पुराना तरीका: ब्राउज़र का प्रिंट (Windows ड्राइवर)। लेबल की बारीक सेटिंग (उल्टा/गैप/गहराई) मालिक से (settings.lblCfg) लैपटॉप पर भी।
  - लैपटॉप पैनल (≥1100px) पहले से: दाएँ "चालू बिल", कीबोर्ड: / या F2 = खोज, F9 = बिल, Esc = बंद। बारकोड-गन = कीबोर्ड (सीधा चलता)।
  - "📥 इस कंप्यूटर पर ऐप इंस्टॉल करें" बटन (beforeinstallprompt)। जाँच tests/desk.py (नकली serial)।
