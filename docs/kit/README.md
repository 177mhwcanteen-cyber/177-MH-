## दो रास्ते

### रास्ता A — दूसरे खाते के Claude के पास GitHub हो (सबसे अच्छा, सीधा ऐप तक)
दूसरे खाते में भी उसी GitHub (177mhwcanteen-cyber) से जुड़ा Claude हो (कोड वाला सत्र, जैसे यही), तो कोई ZIP नहीं चाहिए।
विक्रम जी वहाँ **यह लिखें**:
```
177 MH कैंटीन ऐप का काम है। GitHub रिपो 177mhwcanteen-cyber/177-MH- जोड़ो।
पहले CLAUDE.md, फिर docs/सामान-इनबॉक्स/README.md पढ़ो और ठीक वैसे ही काम करो।
मैं रैक-वार सामान की फोटो भेज रहा हूँ — पहले सिर्फ़ जमा करो (scripts/foto.py), मेरे "अब काम करो" कहने पर
ध्यान से खेप बनाकर ऐप तक पहुँचाओ। मुझे "विक्रम जी" कहो, छोटे जवाब दो। बिलिंग मेरे कहे बिना कभी चालू मत करना।
```

### रास्ता B — सामान्य Claude ऐप (बिना GitHub) → ZIP → ऐप वाला Claude
1. विक्रम जी यह किट डाउनलोड करें: `docs/kit/mh177-saman-kit-v6.zip`
   (सीधा लिंक: https://github.com/177mhwcanteen-cyber/177-MH-/raw/main/docs/kit/mh177-saman-kit-v6.zip)
2. दूसरे Claude खाते में **नई बातचीत** खोलें, किट की ZIP लगाएँ, और **यह लिखें**:
```
यह 177 MH कैंटीन (बाड़मेर) का सामान चढ़ाने का किट है। ZIP खोलो और 00-पहले-यह-पढ़ो.md पूरा पढ़ो — ठीक उसी
तरीके से काम करना है, कुछ भी छोड़ना या गढ़ना नहीं। मुझे "विक्रम जी" कहो, छोटे जवाब दो।
अब मैं रैक-वार सामान की फोटो भेजूँगा — पहले सिर्फ़ जमा करना (एक लाइन जवाब), मेरे "अब काम करो" कहने पर
ध्यान से हर सामान बनाना और tools/jaanch.py से जाँचकर mh177-kaam-….zip देना।
```
3. फोटो भेजते जाएँ ("रैक 6" लिखकर)। फिर "अब काम करो" लिखें।
4. जो **mh177-kaam-S-….zip** मिले, उसे ऐप वाले (इस) Claude को भेजकर लिखें:
   **"यह दूसरे Claude की ZIP है, ऐप में चढ़ा दो"**।

(दूसरे Claude में "कोड चलाना / फ़ाइल बनाना" वाली सुविधा चालू हो तो सबसे अच्छा, क्योंकि वह ZIP और फोटो खुद बनाता है।
चालू न हो तो वह JSON टेक्स्ट देगा, और फोटो विक्रम जी को ऐप वाले Claude को दोबारा भेजनी होंगी।)

## 🤖 ऐप वाले Claude के लिए: ZIP आए तो
1. `git pull --rebase` → `python3 scripts/kit_import.py <zip> --dry` (देखो: ❌, ⚠, appId, सवाल)
2. ❌ हों तो stock.json सुधारो (फोटो देखकर), या विक्रम जी से पूछो। ⚠ "यह बारकोड ऐप में पहले से" आए तो कोई दिक्कत नहीं:
   ऐप बारकोड से मिलाकर सिर्फ़ खाली खाने भरता है।
3. `python3 scripts/kit_import.py <zip>`. यह असली फोटो फोटो-शाखा में push करता है, खेप बनाता है (web/data/items + web/p),
   कंपनियाँ (`docs/सामान-इनबॉक्स/companies.json`), सवाल (`sawal.md`) और पूरी जानकारी (`docs/सामान-इनबॉक्स/kaam/<batch>.json`:
   desc, geminiPrompt, ingredients — आगे ऑनलाइन दुकान के लिए) भी सँभालता है।
4. `node scripts/build.mjs` → `tests/packs.py` + e2e → commit/push (web/data, web/p, docs) → `python3 scripts/kit.py`
   (किट की 03/09/10 ताज़ा) → push।
5. विक्रम जी को 3–6 लाइन: "N सामान ऐप में भेजे (अपडेट दबाएँ), M कंपनी, K का बारकोड तैयार (बारकोड पहरा → रैक), सवाल: …"।
